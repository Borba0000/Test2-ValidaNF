📡 Configuração do Proxy Local
⚠️ Chamadas SOAP à SEFAZ com certificado A1 precisam de um proxy local (restrição de CORS + mTLS no browser). Configure em ~3 minutos.
1 · Instale o Node.js e prepare a pasta
mkdir proxy-sefaz && cd proxy-sefaz npm init -y npm install express node-fetch@2 cors
2 · Crie o arquivo server.js
const express = require('express'); const fetch = require('node-fetch'); const https = require('https'); const cors = require('cors'); const app = express(); app.use(cors()); app.use(express.json({ limit: '10mb' })); app.post('/consultar', async (req, res) => { try { const { soapXml, pfxBase64, pfxPassword, url } = req.body; const pfx = Buffer.from(pfxBase64, 'base64'); const agent = new https.Agent({ pfx, passphrase: pfxPassword }); const resp = await fetch(url, { method : 'POST', agent, headers: { 'Content-Type': 'application/soap+xml; charset=utf-8', 'SOAPAction' : soapAction || '', 'Accept' : 'application/soap+xml' }, body: soapXml }); const xml = await resp.text(); res.set('Content-Type', 'text/xml').send(xml); } catch (err) { res.status(500).json({ error: err.message }); } }); app.listen(3000, () => console.log('✅ Proxy SEFAZ: http://localhost:3000') );
3 · Inicie o servidor
node server.js
✅ Com o proxy rodando, o ValidaNFe se conecta automaticamente a localhost:3000. URL configurável em ⚙️ Config.
